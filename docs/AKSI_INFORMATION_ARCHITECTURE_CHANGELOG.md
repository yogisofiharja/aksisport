# AKSI Information Architecture — Change Log

Historical record of changes to `AKSI_INFORMATION_ARCHITECTURE.md`. That
document is the source of truth for the *current* architecture; this
file is append-only history — never a place to look for what's true
right now.

## v1.1.0

- Community Navigation is Home · Sessions · Chat · Members. Members moves
  from contextual access to a permanent tab, the same for every role
  (organizer-only actions inside it); join requests also stay as a callout
  on Community Home for owners and admins. Settings stays contextual, in
  the Community's ⋯ menu.
